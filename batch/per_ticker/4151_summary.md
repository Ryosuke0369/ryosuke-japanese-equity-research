■**製薬の恒等式**: 当社は 売上 − COGS − SGA が営業利益にならない（研究開発費が yfinance の SG&A に含まれないため）。テンプレは OP = 売上 − COGS − SGA で計算するので、**COGS% を実績水準 25.8% に固定し SGA% = 100% − COGS% − 目標OPM で逆算**した。したがって本モデルの SGA 行は「販管費 + 研究開発費」の合計を表す。既存銘柄からの流用なし。

NWC（実績4期平均）: DSO 112 / DIH 231 / DPO **323** 日。実績4期平均。■DPO が極端に長いのは、当社の COGS 比率が 25.8% と低く、仕入債務・未払費用を COGS で割ると日数が膨らむため。テンプレは AP = COGS × DPO/365 で計算するので、cogs_pct を実績水準に固定している限り仕入債務残高は実績を再現する。ただしシナリオ間で cogs_pct を動かすと AP が比例して動く点には留保が必要。

## 10. 未解決事項（人間の判断を要する）

1. 売上成長がほぼ停止している（FY2025/12 YoY +0.26%） — Base の成長パス（Y1 +2.0% → Y5 +2.5%）はパイプラインの寄与を前提としているが、直近の報告売上はそれを示していない。中期経営計画との突合が必要。
2. capex 逓減の仮定が Target を支配している — 直近2期の capex は D&A の3倍超（FY2024 105,268 / FY2025 83,519 対 D&A 24,780 / 26,144）。5年で D&A 水準まで下げる仮定は会社が表明した計画ではなく本モデルの設計判断であり、高止まりすればターミナルFCFは大きく下振れる。
3. 希少疾患ポートフォリオの集中リスク — 収益が少数の製品に集中しており、単一の償還・競合イベントが業績を大きく動かす。5年単一パスの DCF（WACC 7.87%）はこの分散を表現できていない。

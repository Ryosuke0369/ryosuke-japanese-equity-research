NWC（実績4期平均）: DSO 127 / DIH 379 / DPO **430** 日。実績4期平均。■DPO 430日が極端に長いのは、当社の COGS 比率が低く（22-31%）仕入債務・未払費用を COGS で割ると日数が膨らむため。テンプレは AP = COGS × DPO/365 で計算するので、cogs_pct を実績水準に固定している限り仕入債務残高は実績を再現する。ただしシナリオ間で cogs_pct を動かすと AP が比例して動く点には留保が必要。

## 10. 未解決事項（人間の判断を要する）

1. **beta 1.0 が推定であり WACC 10.47% を支配している（最大の未解決）** — 国内製薬同業の実測beta は −0.05〜0.14 で、いずれもクランプ下限 0.60 を下回る。0.60 を使えば Ke = WACC は 7.87% となり Target は大きく上振れ、WARN 11 の乖離も縮小する。**判定が SELL から反転しうる最大の論点**。7974 任天堂と同型。
2. 自社倍率 16.10x と Peer中央値 10.79x の差（ADCプレミアム）をどう扱うか — 本モデルの Exit 法は Peer中央値をそのまま用い、Enhertu / Datroway の ADC フランチャイズに対するプレミアムが永続するとは仮定していない。これが −42.1% の乖離の最大の要因。プレミアムを認めるなら Exit 倍率を引き上げるべきで、その場合 Target は大きく上振れる。
3. FY2026/3 の COGS 率急上昇（22.0% → 31.5%）の要因が未確認 — 営業利益が 331,925 → 229,089 と減少した主因。製品ミックスかロイヤリティ支払か一過性かでBase の妥当性が変わる。
4. capex 逓減の仮定 — 実績 capex は売上比 10.0% まで上昇。5年で D&A 水準（3.6%）まで下げる仮定は会社計画ではなく本モデルの設計判断。

## 11. 追補6 §X による乖離裁定（第7セッション）

> **本銘柄の Target は追補6 §X の裁定により変更されました。**
> 旧: 中点平均 **3,351円**（−46.1%）／ 新: **5,165円**（−16.9%）

### 裁定の経緯

追補5 までは §Q（Exit > 25倍）と §U（分母トラフ）がそれぞれ独立のトリガーを持っていたため、
**乖離が大きくてもどちらの条件も満たさない銘柄は、禁止されているはずの中点平均がそのまま Target になっていた**。
追補6 §X は**乖離そのものを単独の裁定トリガー**に変え、§Q / §U を「どちらの脚を落とすかの判断材料」に格下げした。

### 本銘柄の裁定

| 項目 | 値 |
|---|---|
| 乖離 | **3.73倍**（> 3.0倍 → 中点平均禁止） |
| レジーム判定 | 仮定Exit **15.60倍** ≤ 25倍 → 成長プレミアム（§Q）ではない／ 直近OPM 7.19% > 窓p25 6.46% → トラフ（§U）でもない → **通常レジーム** |
| Peer 実測 EV/EBITDA バンド（p25–p75） | **15.02–18.26倍** |
| PGM逆算倍率 | **4.19倍** → **バンド外** |
| 仮定Exit倍率 | **15.60倍** → バンド内 |
| **裁定** | **PGM法を[参考]に降格 → Target = Exit 単独 5,165円（−16.9%）** |

**バンドテストの位置づけ**: 市場倍率を無条件のアンカーにするものではない（それではスクリーナーが市場の複写に堕する）。
**実際に取引されているレンジの外に出た脚だけを取り除く**という設計である。

### Exit法は同業内で保守的な水準にある

仮定Exit **15.60倍** は Peer バンド 15.02–18.26倍 の**下端寄り**にあり、自社の現在倍率 **14.58倍** とも近い。
Peer選定の妥当性は第6セッションで既に確認済み（自社倍率と Peer中央値が近いこと自体が傍証）。

裁定後も判定は **SELL** のままで、変わったのは下落幅（−46.1% → −16.9%）である。
**方向は中点平均でも Exit 単独でも一致しており、モデル依存なのは幅だけ**という点は 6752 と同じ構図。

## 12. 追補6 §X による乖離裁定（第7セッション）

> **本銘柄の Target は追補6 §X の裁定により変更されました。**
> 旧: 中点平均 **1,871円**（−59.1%）／ 新: **2,867円**（−37.3%）

### 裁定の経緯

追補5 までは §Q（Exit > 25倍）と §U（分母トラフ）がそれぞれ独立のトリガーを持っていたため、
**乖離が大きくてもどちらの条件も満たさない銘柄は、禁止されているはずの中点平均がそのまま Target になっていた**。
追補6 §X は**乖離そのものを単独の裁定トリガー**に変え、§Q / §U を「どちらの脚を落とすかの判断材料」に格下げした。

### 本銘柄の裁定

| 項目 | 値 |
|---|---|
| 乖離 | **3.55倍**（> 3.0倍 → 中点平均禁止） |
| レジーム判定 | 仮定Exit **15.00倍** ≤ 25倍 → 成長プレミアム（§Q）ではない／ 直近OPM 8.73% ≤ 窓p25 9.18% → トラフ（§U）だが、**§Y のトレンド整合ルールで再生成済み**のため 3. へ |
| Peer 実測 EV/EBITDA バンド（p25–p75） | **14.58–15.55倍** |
| PGM逆算倍率 | **4.22倍** → **バンド外** |
| 仮定Exit倍率 | **15.00倍** → バンド内 |
| **裁定** | **PGM法を[参考]に降格 → Target = Exit 単独 2,867円（−37.3%）** |

**バンドテストの位置づけ**: 市場倍率を無条件のアンカーにするものではない（それではスクリーナーが市場の複写に堕する）。
**実際に取引されているレンジの外に出た脚だけを取り除く**という設計である。

### 併せて追補6 §Y により Base シナリオを差し替えた（重要）

**§Y の裁定: トレンドがサイクルに優先する。**

第6セッションでは追補5 §U のシグネチャに該当したため §4-4 のミッドサイクル正常化
（ピーク・トラフ中間 **10.51%**）を適用したが、**追補6 §Y によりこれを凍結した**。

> §4-4 は「平均への回帰」を前提とするが、**単調トレンドに平均回帰を当てるのは統計的な誤り**である。
> FA需要減が構造的なら、中央値への回帰は楽観バイアスになる（第6セッションで自ら報告した懸念のとおり）。

**確定した優先順位**: ① OPM系列が単調（増加または減少）→ **トレンド整合ルール**（2267 先例）／
② 非単調（変動）系列のみ §4-4 の中央値収束。本銘柄は①に該当する。

| | Base 到達OPM | Target |
|---|---|---|
| 追補5 §U 版（凍結） | 10.51%（§4-4 ピーク・トラフ中間） | 3,096円 |
| **追補6 §Y 版（採用）** | **9.58%**（単調減少の特則・2267先例） | **2,867円** |

型判定は **型B疑い（分母トラフ型）・要目視レビュー** のまま維持している（分母が窓の谷にある事実は変わらないため）。

### 乖離の主因は割引率の不整合として定量できる

仮定Exit **15.00倍** は FCF/EBITDA 53.4% の下で r − g = 3.56%、すなわち **割引率 4.56% を含意する**。
これに対し本モデルの WACC は **11.50%**（beta 1.237 + size premium 1.0%）。
**2本の脚は約 7pt も異なる割引率を仮定している。**

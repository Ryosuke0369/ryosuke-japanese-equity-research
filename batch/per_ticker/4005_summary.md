## 5. シナリオ5本の含意営業利益率 検算テーブル

実績OPM（直近4期）: min **−17.63** / p25 −5.03 / med 2.89 / p75 7.05 / max **8.38** %

| シナリオ | 到達OPM（Y5） | 導出ルール |
|---|---|---|
| **Base** | **5.64%** | §4-4 の「ピークとトラフの中間」は使えず（下記）→ (直近実績 8.38 + 実績中央値 2.89)/2（Y1 8.0% → Y5 5.64%） |
| **Upside** | **9.38%** | max(実績max 8.38, 直近+1.0pt = 9.38) = 直近+1.0pt（サイクルピークの再現） |
| **Management** | Base と同一 | **会社予想が取得できず**（生成ログ Step 3「No guidance data found」）→ v2 §7-2 |
| **Downside 1** | **2.89%** | 実績p25(−5.03%)は減損計上年に汚染されているため使えず、**実績中央値 2.89%** を到達点とした |
| **Downside 2** | **−2.0〜+0.5%** | 営業上のトラフ FY2023/3 の −0.8% を起点に売上 −12% を重ねた |

■**§4-4 からの意図的な逸脱**: §4-4 は Base を「ピークとトラフの中間」とするが、当社のトラフ（−17.63%）は住友ファーマ等の**減損計上年であって営業上の谷ではない**。そのまま適用すると Base の到達OPMが **−4.63%** という無意味な値になる。したがって (直近実績 + 実績中央値)/2 = 5.64% とし、現在のピーク側水準からミッドサイクルへの「緩やかな正常化」を置いた。同じ理由で Downside 1 の p25 も使えないため実績中央値を用いている。

COGS% / SGA% は `100% − OPM − 他方` の恒等式で構成（SGA% は構造改革後の直近水準 24.5% を基準に調整）。既存銘柄からの流用なし。

## 10. 未解決事項（人間の判断を要する）

1. 減損年（FY2024/3 OPM −17.63%）を「営業上の谷」とみなすかどうか — 本モデルは減損年を営業サイクルの谷ではないと判断し、Base・Downside 1 の導出から除外した。住友ファーマの事業価値がさらに毀損する可能性を織り込むなら、Downside はより深く設計すべきである。
2. 実績Kd 5.23%（税引前）の妥当性と WACC への影響 — D/E 0.96 のため Kd が WACC を Ke 7.87% から 5.94% へ 1.93pt 押し下げている。Kd を国内実勢の 3% に置けば WACC は約 6.9% となり Target は下振れる。EDINET 有報の支払利息との突合が必要。
3. 構造改革の完了時期 — 売上は3期連続で減少（事業売却）しており、Base の成長パス（Y1 0% → Y5 +2.0%）はポートフォリオ整理が終わったことを仮定している。有報はまだそれを確認していない。

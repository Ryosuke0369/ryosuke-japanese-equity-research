## 10. 未解決事項（人間の判断を要する）

1. **自社倍率 21.37x と Peer中央値 12.35x の差（防衛・エネルギープレミアム）をどう扱うか** — 本モデルの Exit 法は Peer中央値をそのまま用い、当社のプレミアムが永続するとは仮定していない。これが −56.4% の乖離の最大の要因。防衛予算の増額が構造的と判断するなら Exit 倍率を引き上げるべきで、その場合 Target は大きく上振れる。
2. 売上が FY2026/3 に −12.32% と落ちている — マージンは維持されているが売上は減少した。Base の成長パス（Y1 +3.0%）は受注の売上化を前提としており、報告売上はまだそれを示していない。
3. 長納期プロジェクトの損失計上リスク — 3年前の OPM は 4.28% と現在の半分。大型案件の採算悪化は過去にも起きており、Downside 2（4.3-5.0%）はその再現を想定している。
4. **core_ebitda の破綻が validate をすり抜けた** — 追補2 §G のゲート（check_core_ebitda.py）がなければ、Comps 参考株価 583円 という誤値のまま納品されていた。同種のリスクは D&A のタグ付けが特殊な IFRS 適用会社で再発しうる。

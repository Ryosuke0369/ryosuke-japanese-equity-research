## 11. 追補5 §V-1 の再生成（第6セッション）

### 11-1. 何を変えたか

| 項目 | 初回生成 | 再生成 |
|---|---|---|
| 型判定 | 型A | **型B疑い（分母トラフ型）・要目視レビュー** |

| Upside 到達OPM | 4.35%（p75） | **4.81%**（型B規則 = サイクルピーク再現） |

**capex の一次ソース（追補3 §O の手順）**: EDINET 有価証券報告書 **docID S100YETA**（FY2026/3、取得日 2026-09-05）の
`PurchaseOfPropertyPlantAndEquipmentInvCFIFRS` 622,955 + `PurchaseOfIntangibleAssetsInvCFIFRS` 73,063 = **696,018百万円**。
**検証**: 同2要素の前期合計 772,332 + 91,038 = **863,370** が yfinance の FY2025/3 capex と完全一致（追補1 §D-3 の数値照合）。
初回の仮定値 700,000 はほぼ正しく、**PGM を押し下げていた主因は capex ではなかった**ことが確認できた。

### 11-2. 再判定の結果 — 乖離は収斂しなかった（4.31倍 → **4.41倍**）

§U はミッドサイクル正常化で乖離が3.0倍以内に収斂することを期待していたが、**わずかに拡大**した
（中点 Target は 1,661円 → 1,644円、変化は17円 = 1%）。

**なぜ効かなかったか**: 初回生成の Base は既に到達OPMを中央値 3.81% に置いており、
**ターミナル年で谷の利益を資本化してはいなかった**。谷にあったのは明示予測期間の前半（Y1 2.9%）だけで、
ターミナル価値が支配的な DCF では Y1-Y2 の水準は結果をほとんど動かさない。
§4-4 の型B規則に切り替えると到達OPMはむしろ 3.81% → 3.71% と下がるため、乖離は微増した。

### 11-3. 真の原因は資本集約度

実績 **capex / D&A** 比: **0.97 → 1.62 → 2.13 → 1.72**（車載電池の能力投資）。
D&A が売上の約5.0%と大きい一方 capex がその1.7〜2.1倍で持続するため、**EBITDA と FCF が3倍以上開く**。

- **Exit法**は EBITDA を評価する（capex を控除しない）
- **PGM法**は FCF を永久還元する（capex を控除する）

→ **capex/D&A が持続的に1.5倍を超える資本集約型では、2本の評価法が機械的に乖離する。**
利益率の谷を是正しても解消しない。

### 11-4. §U ステップ2 の個別判断 — **PGM を降格、Target = Exit 単独**

§U は「安易な中点平均を禁止」し「どちらを正とするか個別判断を記録した上で歪んだ脚を[参考]降格可」としている。

| | 値 | 判断 |
|---|---|---|
| PGM | 448円（−89.2%） | **[参考・Target不算入 — 追補5 §U] に降格** |
| Exit | **2,840円（−31.8%）** | **Target として採用** |
| （中点） | 1,644円 | §U が禁じる「どちらの世界観にも属さない中点」→ **不採用** |

**なぜ PGM を降格したか**

1. PGM逆算のターミナル EV/EBITDA は **3.24倍**で、上場する事業会社が実際に取引される倍率の下限を大きく下回り、
   **ターミナル価値として経験的に成立しない**。**片方の脚が観測可能な範囲の外に出た場合は、内側にある脚を正とする。**
2. 仮定Exit 14.30倍は独立に裏付けが取れる: EV（時価総額 9,720,293 + ネットデット 833,018 = 10,553,311）÷
   ミッドサイクルEBITDA 773,181 = **13.65倍** ≈ Peer中央値 14.30倍。
3. 乖離の原因は本銘柄固有の洞察ではなく、**永久成長率1.0%固定の単段階モデルが資本集約型を評価しきれない
   という既知のモデル上の限界**（バッチレポート §13 ／ 追補4 §R で2段階成長モデルをバッチ後課題として登録済み）。
   **モデルの既知の欠陥を銘柄固有の投資判断として出力してはならない。**

**逆（Exit降格）を採らなかった理由**: Target = PGM単独 448円（−89%）となり、
追補5 §U 自身が「中点より悪い」と警告した状態に落ちるため。

**方向性は両脚で頑健**: Exit単独 2,840円（−31.8%）でも PGM単独 448円（−89%）でも判定は **SELL** で一致する。
**モデル依存なのは下落幅であって方向ではない。**

逆算DCF（Block F）: 現値 4,163円 は定常営業利益 **1,299,967百万円**（FY2025サイクルピーク 406,534 の **3.20倍**）を要求する。
ランプなしでも 1,111,980百万円（ピークの2.74倍）が必要で、**現値はミッドサイクルの経済性では説明できない**。

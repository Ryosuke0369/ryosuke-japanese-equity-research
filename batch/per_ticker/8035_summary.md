**【本銘柄群で最重要】PGM と Exit が5倍以上乖離している。Target を点推定として読んではいけない。**

半導体製造装置セクターは現在バリュエーションがサイクル高値圏にあり、Peer中央値 EV/EBITDA が 30倍超という異例の水準にある。一方、本バッチのグローバル前提（永久成長率 **1.0%** 固定、ERP 6.5%、size premium 1.0%）でPGM を計算すると、逆算される Exit 倍率は **5〜7倍**にしかならない。両者は同じ会社について**まったく異なる世界観**を述べており、Target はその中点にすぎない。

- **§4-4 の「ピーク利益×高Exit倍率の二重計上禁止」は形式的には満たしている**（Exit 倍率は Peer 中央値ちょうどで、それを超えていない。かつ Base はピーク利益ではなくミッドサイクル利益を使っている）。
- しかし**実質的には「ミッドサイクル利益 × 高値圏の倍率」という半端な状態**であり、§4-4 が警告した risk は残っている。
- **根本にあるのは倍率の選び方ではなく、永久成長率 1.0% という前提**である。市場が 30倍を払うのは、この事業の長期成長が 1% をはるかに超えると見ているためで、g=1.0% を置く限り DCF は構造的に市場倍率と両立しない。
- **人間の判断を要する**: (a) 当セクターに限り terminal_growth を引き上げる、(b) 二段階成長モデルに切り替える、(c) Exit 法を参考扱いにして PGM 単独で読む、のいずれかが必要。

## 10. 未解決事項（人間の判断を要する）

1. **PGM 9,967円 と Exit 42,869円 が4.3倍乖離しており Target は中点にすぎない（本バッチ最大の手法間乖離）** — 6146 / 6857 と同じ構造的問題。永久成長率 1.0% の前提とセクターの 36倍の倍率は両立しない。**加えて当社は beta 1.332 で WACC 12.62% と本バッチ最高**のため、PGM が特に低く出ている。beta が高いこと自体は市場の見方の反映であり誤りではないが、g=1.0% との組み合わせが PGM を極端に押し下げている。
2. サイクルが利益率ではなく売上に出る — OPMレンジは 3.8pt と狭いが、売上は1年で 17% 落ちた実績がある。**利益率の安定性を『サイクルが浅い』と読むと誤る**。Downside 2 で売上 −25% を置いたのはこのため。
3. capex が売上比 9.0% まで上昇し D&A の3倍近い — 5年で D&A 水準まで下げる仮定は会社計画ではない。高止まりすればターミナルFCFは大きく下振れる。

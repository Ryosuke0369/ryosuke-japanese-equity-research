## 5. シナリオ5本の含意営業利益率 検算テーブル

実績OPM（直近4期）: min **−5.30** / p25 3.22 / med 7.44 / p75 9.13 / max **10.07** %

| シナリオ | 到達OPM（Y5） | 導出ルール |
|---|---|---|
| **Base** | **8.76%** | §4-4 の「ピークとトラフの中間」は使えず（下記）→（直近実績 10.07 + 実績中央値 7.44）/2（Y1 9.8% → Y5 8.76%） |
| **Upside** | **11.07%** | max(実績max 10.07, 直近+1.0pt = 11.07) = 直近+1.0pt |
| **Management** | Base と同一 | **会社予想が取得できず**（生成ログ Step 3「No guidance data found」）→ v2 §7-2 |
| **Downside 1** | **7.44%** | 実績p25(3.22%)は**赤字年に汚染**されているため使えず、**実績中央値 7.44%** を到達点とした |
| **Downside 2** | **2.0–4.0%** | **赤字年の再現ではなく事業悪化として設計**し、売上 −10% + OPM 2.0–4.0% とした |

■**§4-4 からの意図的な逸脱（4005 住友化学と同じ扱い）**: §4-4 は Base を「ピークとトラフの中間」とするが、当社のトラフ（−5.30%）は民間航空エンジン関連の**一過性費用による赤字年であって営業上の谷ではない**。そのまま適用すると Base 到達OPMが 2.39% という実勢とかけ離れた値になる。したがって（直近実績 + 実績中央値）/2 = 8.76% とした。同じ理由で **Downside 1 の p25（3.22%）も使えず実績中央値**を用いている。

■**恒等式の扱い**: 当社は 売上 − COGS − SGA が営業利益に完全一致しない（その他営業損益が存在する）。**COGS% を実績水準に固定し SGA% = 100% − COGS% − 目標OPM で逆算**した。本モデルの SGA 行は「販管費 ± その他営業損益」を表す。COGS% は直近実績 76.9% に固定した。既存銘柄からの流用なし。

NWC（実績4期平均）: DSO 117 / DIH 133 / DPO 91 日。実績4期平均。DSO+DIH が250日を超え、長納期プロジェクトの運転資本負担が重い。

## 10. 未解決事項（人間の判断を要する）

1. **赤字年（FY2024/3 −5.30%）を「営業上の谷」とみなすかどうか** — 本モデルは一過性費用による赤字であり営業サイクルの谷ではないと判断し、Base・Downside 1 の導出から除外した。民間航空エンジンの費用計上が再発性であれば、Downside はより深く設計すべきである。

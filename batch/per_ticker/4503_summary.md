## 5. シナリオ5本の含意営業利益率 検算テーブル

実績OPM（直近4期）: min 1.18 / p25 1.87 / med 5.38 / p75 10.94 / max **17.77** %

| シナリオ | 到達OPM（Y5） | 導出ルール |
|---|---|---|
| **Base** | **14.36%** | 直近実績 17.77% > 実績中央値 → (直近実績 + p75)/2（Y1 17.0% → Y5 14.36%） |
| **Upside** | **18.77%** | max(実績p75 10.94, 直近+1.0pt = 18.77) = 直近+1.0pt |

| **Downside 1** | **5.38%** | 実績p25(1.87%)は**減損計上年の値**で「緩やかな悪化」を表さないため、**実績中央値 5.38%** を到達点とした（4005 と同じ扱い） |
| **Downside 2** | **2.0–3.0%** | **減損の再現ではなく事業悪化として設計**し、売上 −8% + OPM 2.0–3.0% とした |

■**分布そのものが歪んでいる**: 中間2期（1.18% / 2.10%）は無形資産減損による一過性の落ち込みで、p25 が「緩やかな悪化」を表さない。したがって Downside 1 は実績中央値を用いている。

■**製薬の恒等式**: 当社は 売上 − COGS − SGA が営業利益にならない（研究開発費・無形資産償却が yfinance の SG&A に含まれない）。**COGS% を実績水準 19.1% を基準に置き SGA% = 100% − COGS% − 目標OPM で逆算**した。本モデルの SGA 行は「販管費 + 研究開発費 + 無形資産償却」の合計を表す。既存銘柄からの流用なし。

NWC（実績4期平均）: DSO 118 / DIH **284** / DPO 196 日。実績4期平均。DIH 284日・DPO 196日はいずれも長く、両者がある程度相殺する構造。

1. **capex_pct 9.56% がターミナル収束のための人為的水準である** — 直近実績は 4.0%。D&A が capex を大きく上回る（買収無形資産の償却）構造に対し、本モデルは capex を引き上げて収束させた。4502 と同様に da_direct で D&A を逓減させる設計の方が経済実態に近い可能性がある。どちらを採るかは人間の判断を要する。

3. 減損の再発リスク — 4期のうち2期で無形資産の減損を計上している。本モデルの Downside 2 は減損ではなく事業悪化で設計しており、3回目の減損は織り込んでいない。
4. オンコロジー製品への収益集中と独占期間 — 収益が少数の製品に集中し、独占期間は有限。terminal_growth 1.0% は特許切れの断崖を表現していない。

## 追補8 §AE の rework wave（第8セッション）

> **本銘柄の Base シナリオは追補8 §AE により再設計されました。**
> Target: **4,095円 → 4,150円**（BUY / 42.7%）

【追補8 §AE の rework wave（第8セッション）】追補7 §Y の単調性判定と、追補8 §AE-2 が確定した方向別の定義に従って **Base を再設計**した。■実績OPM: 0.08% → 0.08% → 0.10% → 0.11%。**判定: 単調増加**。■**適用ルール: 単調増加 → 直近水準の維持** により Base 到達OPM = **10.88%**（旧: 10.62%、差 +0.26pt）。■**平均回帰（§4-4 の中央値収束）は使わない**: トレンドに平均回帰を当てるのは統計的な誤りであり、その理由は符号で変わらない（追補8 §AE-2）。**単調増加では『さらなる上積みの外挿はしない』という保守側のガード**を置き、直近水準の維持とした。■Upside / Downside 1 / Downside 2 は本 rework の対象外で、従前の設計を維持している。■COGS% は据え置き、SGA% = 100% − COGS% − 目標OPM で逆算した。

**§AE-2 が確定した方向別の定義**

| OPM系列 | トレンド整合ルールの定義 |
|---|---|
| **単調増加** | **直近水準の維持**（さらなる上積みの外挿はしない = 保守側のガード） |
| **単調減少** | **(直近 + 中央値)/2**（2267 先例） |
| 非単調 | §4-4 の中央値収束 / (直近 + p75)/2 |

**なぜ平均回帰を使わないか**: トレンドに平均回帰を当てるのは統計的な誤りであり、**その理由は符号で変わらない**（追補8 §AE-2）。

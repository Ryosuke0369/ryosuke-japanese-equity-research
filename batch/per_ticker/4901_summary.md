## 9. 使用したフォールバック一覧

1. 会社業績予想を EDINET XBRL・TDnet短信のいずれからも取得できず、Management=Base で続行（v2 §7-2。本バッチ全銘柄で同じ結果であり、銘柄固有ではなくパイプラインの構造的な取得失敗）
2. ターミナル年の capex/D&A を 1.05倍に収束させるための capex 逓減パスは**会社が表明した計画ではなく本モデルの仮定（推定）**
3. 追補2 §F-2 / 追補3 §L / 追補2 §G の予防的補完を生成前適用（hist_years 置換 + P/L 5系列 + net_debt + core_ebitda + current_price + shares_outstanding を明示指定。CF/BS 5系列は align_hist_series_to_years() が再マップするため渡していない）
4. beta は yfinance実測がクランプ下限 0.60 を下回るため、追補1 §A の規則 max(0.6, min(1.75, 実測)) により**0.60 を明示指定**（テンプレの無言の 1.0 置換は回避済み。実測ベースより WACC は保守的に出る）
5. **yfinance の FY2025 の D&A・capex・営業CFが FY2024 と完全に同値**（150,014 / 464,712 / 407,941）で、生成前チェック（`batch/pregen_check.py`）が重複を検出した。**直近期 FY2026/3 の値は重複しておらず**（D&A 172,371 / capex 570,566）、本モデルは P/L 5系列のみを渡すため FY2025 の破損は伝播しない。EDINET 有報 docID **S100YIBH** の設備投資額 **506,945百万円** と yfinance の capex 570,566 は定義が異なる（設備投資額 vs CF計算書の取得支出）ため、比率ベースの前提には yfinance 側を採用した

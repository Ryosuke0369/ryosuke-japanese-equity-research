## 11. 追補6 §X による乖離裁定（第7セッション）

> **本銘柄の Target は追補6 §X の裁定により変更されました。**
> 旧: 中点平均 **2,462円**（−65.8%）／ 新: **3,612円**（−49.8%）

### 裁定の経緯

追補5 までは §Q（Exit > 25倍）と §U（分母トラフ）がそれぞれ独立のトリガーを持っていたため、
**乖離が大きくてもどちらの条件も満たさない銘柄は、禁止されているはずの中点平均がそのまま Target になっていた**。
追補6 §X は**乖離そのものを単独の裁定トリガー**に変え、§Q / §U を「どちらの脚を落とすかの判断材料」に格下げした。

### 本銘柄の裁定

| 項目 | 値 |
|---|---|
| 乖離 | **4.55倍**（> 3.0倍 → 中点平均禁止） |
| レジーム判定 | 仮定Exit **17.20倍** ≤ 25倍 → 成長プレミアム（§Q）ではない／ 直近OPM 15.39% > 窓p25 14.83% → トラフ（§U）でもない → **通常レジーム** |
| Peer 実測 EV/EBITDA バンド（p25–p75） | **11.68–18.09倍** |
| PGM逆算倍率 | **3.78倍** → **バンド外** |
| 仮定Exit倍率 | **17.20倍** → バンド内 |
| **裁定** | **PGM法を[参考]に降格 → Target = Exit 単独 3,612円（−49.8%）** |

**バンドテストの位置づけ**: 市場倍率を無条件のアンカーにするものではない（それではスクリーナーが市場の複写に堕する）。
**実際に取引されているレンジの外に出た脚だけを取り除く**という設計である。

### 本銘柄が追補6 §X 導入の直接の契機になった

乖離 **4.55倍** は、追補5 §U で個別裁定した 6752（4.41倍）・6506（3.55倍）より**大きい**。
にもかかわらず、直近OPM 15.39% が窓p25 14.83% を**わずか 0.56pt** 上回るというだけで §U の第1条件を外れ、
§Q も仮定Exit 17.20倍 ≤ 25倍で非該当となり、**中点平均 2,462円 がそのまま Target になっていた**。

> **乖離の大きさで見れば最優先で個別判断すべき銘柄が、それとほぼ無関係な基準（分母がトラフか）で素通しされていた。**
> 追補6 §X はこの穴を塞ぐために導入された。

### 現値との隔たりは依然として大きい（−49.8%）

自社倍率 27.15倍 は Peer中央値 17.19倍 の 1.58倍で、市場は MLCC フランチャイズに大きなプレミアムを付けている。
本モデルはそれを仮定していないため、**この Target は「プレミアムが剥落した場合の水準」として読むこと**。

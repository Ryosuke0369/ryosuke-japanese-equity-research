## 3. net_debt 構成

```
有利子負債              0 百万円  ← 当社は無借金
− 現金及び現金同等物  1,791,802 百万円
= net_debt         −1,791,802 百万円（ネットキャッシュ）
```

- **有利子負債ゼロは抽出漏れではなく事実**: EDINET側の年度突合が `Debt 0/6` を報告し、yfinance の連結BSにも `Total Debt` 行自体が存在しない。両ソースが一致。
- **保守的な定義**: 短期有価証券（定期預金等）は「現金及び現金同等物」に含まれないためネットキャッシュから除外。含めればネットキャッシュは拡大し株式価値は上振れる。
- ネットキャッシュのため **D/E = 0 → WACC = Ke**。

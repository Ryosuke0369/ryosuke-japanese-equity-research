# Phase 1: 銘柄型トリアージレポート（90銘柄）

分析基準日: 2026-09-05 / 判定者: Claude Code（バッチモード）

## 判定ルール（機械 + セクター知識のハイブリッド）

判定は**一次データ（yfinance 連結財務諸表 直近5期）**の3指標と、事業構造の知識を併用した。

| 指標 | 定義 | 用途 |
|---|---|---|
| OPM レンジ | 直近5期の営業利益率 max − min | >12pt または 赤字年あり → 型B候補 |
| NonOp/OP | (税前利益 − 営業利益) ÷ \|営業利益\|（最新期） | >+70% → 持分法・営業外主導 = OPベースDCF不成立の疑い |
| Debt/Revenue | 有利子負債 ÷ 売上（最新期） | 製造業で >0.5 → captive finance（型C）の疑い |

判定順序: **① 型C/D/E（構造不成立）→ ② 型B（シクリカル）→ ③ 型A**。
①に該当、または判定に迷うものは §3-1 の指示どおり型Aとして処理せず **キュー送り**（`batch/manual_queue.md`）。

> 注: NonOp/OP は「持分法投資損益」の直接値ではなく (税前−営業) の代理指標である。
> 減損・特損で税前が沈む銘柄では**負に大きく振れる**（例 4188 −97.8%、4502 −130.7%）ため、
> 「利益の主柱がどこにあるか」の判定には**正方向に大きい場合のみ**を採用した。

| 型 | 銘柄数 | 処理 |

| C/D/E・判定困難 | 11 | 生成せずキュー送り |
| **合計** | **90** | |

§1-1 の想定（型C/D/Eは意図的に除外済み）に対し **11 銘柄**がキュー送りとなった。
内訳は **総合商社5 + captive finance 2 + 連結内銀行 2（9434 ソフトバンク・9433 KDDI）+ 持分法主導 1 + 持株型 1**。

> **9433 KDDI は Phase 2 の一次ソース検証で型Eと判明し、パイロット枠から差し戻した**（EDINET 有報 XBRL の連結BSに金融事業の貸出金 6,398,477百万円／預金 5,666,952百万円の独立科目を確認）。詳細は `batch/manual_queue.md`。

> **7974 任天堂 は機械ルール（OPMレンジ16.1pt > 12pt）どおり型B（コンソールサイクル）に分類する**。FY2026/3 は Switch 2 立ち上げ年で OPM が 15.6% まで低下しており、ソフト比率上昇に伴う正常化を Base に織り込む必要がある。
選定趣旨の「型C/D/E除外」は**銀行・保険・証券・自動車OEM・連結内銀行持ち小売**を指していたと解され、
総合商社と販売金融を持つ建機・農機は網から漏れていたと判断する（判定を疑う理由には当たらない）。

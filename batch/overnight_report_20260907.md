## 2. タスク6 — 型F（持分法主導）の設計と実装

### コア損益の定義

商社は **IFRS 上「営業利益」を表示しない**（売上総利益 → 販管費 → その他収益費用 →
金融損益 → 持分法損益 → 税引前利益）。設計書の「連結営業利益から持分法投資損益を除外」は
そのままでは当てられないため、次のように定義した。

```
コア営業利益 = 売上総利益 − 販売費及び一般管理費
```

IFRS の商社 P/L では持分法投資損益・金融収益（**受取配当を含む**）・投資損益・
その他の収益費用がすべて販管費より下にあるため、この定義だけで設計書 §1（持分法損益の除外）と
§2（受取配当の除外・二重計上防止）が**銘柄ごとの個別調整なしに**同時に満たされる。

| ticker | 売上総利益 | − 販管費 | = コア営業利益 | コアOPM | 参考: 持分法損益 |
|---|---:|---:|---:|---:|---:|
| 8001 | 2,480,532 | 1,763,184 | 717,348 | 4.84% | 323,514 |
| 8002 | 1,182,699 | 913,596 | 269,103 | 3.26% | 338,300 |
| 8031 | 1,328,153 | 902,130 | 426,023 | 3.04% | 447,442 |
| 8053 | 1,509,657 | 1,111,394 | 398,263 | 5.43% | 266,672 |
| 8058 | 1,655,074 | 1,236,453 | 418,621 | 2.21% | 467,941 |

8002・8031 は**持分法損益がコア営業利益を上回る**。8058 も僅差。型F が必要な理由そのもの。

### 持分法投資価値

設計書の指示どおり **持分法投資の連結BS残高 × 1.0（簿価）** に統一した。
上場持分先の【簿価】は有報から取得できない ——「関係会社の状況」は資本金と議決権比率のみで、
帳簿価額は個別投資の記述中に散発的に出るだけ（8058 のアングロスール 2,165億円 等）。
非上場分を「BS残高 − 上場分簿価」で求められない以上、上場分だけ時価に置き換えると
二重計上になる。**上場持分の含み益の分だけ保守的（過小）に出る。**
どちらを採ったかは Adjustments Log に記録している。

### net_debt の定義

`社債及び借入金(流動+非流動) − 現金及び現金同等物 + 非支配株主持分`。
リース負債は各社が開示するネット有利子負債の定義に合わせて除外（4社で定義を揃えるため）。
**持分法投資は資産側にあるがコアの FCF を生まないので net_debt では相殺しない**
（相殺すると加算側と二重に効く）。8002 は会社開示のネット有利子負債 1兆8,587億円を使用し、
XBRL からの再現値 1,858,913 と一致することを確認した。8031 は有報 MD&A の
「長短債務合計 57,077億円 − リース負債 5,848億円 = 有利子負債合計 51,229億円」を使用し、
会社開示のネットDER 0.47倍と整合（4,140,178 ÷ 8,767,744 = 0.472）。

## 4. 裁定が必要な事項

### 裁定事項 A（最重要）— 型F の Target が構造的に低く出る

生成した型F 4社はすべて **Target が株価の 40〜50%** で深い SELL になった。
これは設計どおりに動いた結果であり、バグではない。原因は2つある。

1. **コアDCF が構造的に小さい。** コアOPM が 2.2〜5.4% しかない一方、運転資本は収益の
   13.7〜29.6% あり、売上が伸びるほど ΔNWC が FCF を食う。さらに net_debt には
   **連結の有利子負債を全額**入れているが、その一部は持分法投資を賄っている。
   コアEV から全額を引き、持分法を**簿価**で足し戻すと、負債は時価・資産は簿価という
   非対称が残る。
2. **持分法投資価値が簿価。** 設計書の指示どおりだが、商社の持分法持分（資源権益等）は
   含み益が大きく、簿価は下限に近い。8001 の持分法投資 4,104,790 に対し持分法損益は
   323,514 で、**簿価倍率 12.7倍**。仮に持分法先を PER 10倍で評価すれば価値は
   3.2兆 → 3.2兆…（8058 は 5,213,027 に対し 467,941、簿価倍率 11.1倍）。

**裁定していただきたいこと**:
- (a) このまま簿価で確定し、Target が市場の半分になることを「保守的な下限」として受容するか
- (b) 持分法投資を **持分法損益 × 適用倍率**（例: 国内主要投資先の PER 中央値）で評価する
      規則に変えるか
- (c) net_debt のうち持分法投資を賄っている部分を分離する規則を置くか（開示が無いので
      按分規則の裁定が必要）

**8058 だけが生成できなかったのも同じ根**です。8058 はコアOPM 2.21% が5社中最低で、
コアの株主価値が −1,356,013（1株 −370）になります。型F の構成では負のコア株主価値自体は
矛盾ではありません（負債の一部が持分法投資を賄っているため）が、それを Target に流すか
どうかは設計判断なので、**推測で倍率を動かして正の値にすることはしていません**。
(a)〜(c) のいずれかが決まれば 8058 も同じ規則で生成できます。

### 裁定事項 B — 国内ピアが1社以下の銘柄の Comps 規則（2914 JT / 9202 ANAHD）

海外ピアが §5 でバッチ対象外である以上、この2社は現行規則では永久にキューに残ります。
次のいずれかの規則が要ります。
- (a) 近接業種で代替する（JT → 食品・飲料、ANAHD → 陸運・鉄道）。基準混在の是非
- (b) ピア4社以下でも統計を組む（現行の統計式は5社前提）
- (c) `exit_multiple` を自社の過去 EV/EBITDA レンジから置き、Comps は `--no-comps` にする

### 裁定事項 C — 6971 京セラの保有株式の別途加算

型F の「1株別途加算」機構はそのまま使えますが、入力が持分法投資残高ではなく
**投資有価証券（FVTOCI）の時価**になります。加えて含み益に対する繰延税金負債の控除が要ります。
`equity_method` ブロックを一般化して `securities_holding` を受け付けるようにしてよいか、
それとも 6971 は別建てにするか。

### 裁定事項 D（軽微）— 追補13 §C の 6594 について

タスク2 は「未生成の場合のみ」でしたが 6594 は追補13 §B で生成済みのため**スキップ**しました。

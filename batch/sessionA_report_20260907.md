### 型が変わる銘柄：**実質ゼロ**

再スクリーンで分類器の欠陥が2つ見つかり、両方直しました。

**(1) 重要性の下限が無かった。** リース債権や割賦売掛金が数十億円あるだけの会社まで

**金融資産が総資産の 5% 未満なら「検出はしたが型は変更しない」**に修正しました。

**(2) この規則にできないことを2つ明記しました。**

- **(2a) 手数料型の銀行を型D と判定できない。** 8410 セブン銀行は貸出金が総資産の 5.9%
  しかありません（収益の柱が ATM 手数料で、資産の大半が ATM 現金と預け金）。
  銀行かどうかは財務諸表の**様式**（銀行様式＝経常収益・経常利益、`...BNK` タグ）で決まる
  のであって比率では決まりません。**宣言済みの `company_type` が優先**である旨を
  docstring に明記しました。
- **(2b) captive finance（型C）と銀行連結（型E）を区別できない。** 6326 クボタは金融資産が
  35.8% ありますが、中身はクボタ製品の販売金融であって銀行ではありません。自社製品の
  販売金融か第三者向けの金融かは科目名からは分かりません。**型C を維持**します。

> なお 6326 は、前セッションで検出語に `FinancialReceivables` を追加するまで **CLEAN と

## A-1　型F v2

### §3　フロア規則（新設）→ **8058 を解除**

コア脚のエクイティ（EV − net_debt）が負または算定不能なら **コア = 0**、Target は加算脚のみ、
WARN「コアDCF不成立」＋ §AF 相対評価ラベル。

Excel 側で `=MAX(0, IFERROR(<コア式>*1, 0))` として**表に見える形で床を張り**、
「コアDCF 1株値（フロア規則: 負または不成立なら 0）」という行を新設して追える形にしました
（`"N/A"*1` は `#VALUE!` になり `IFERROR` が 0 に、負の値は `MAX` が 0 にします）。

### §1　「残高×1.0」は最終手段であることを表に出す

上場持分先の**簿価**は有報の注記から取得できません（帳簿価額は個別投資の記述に散発的に
出るのみ。8058 のアングロスール 2,165億円 など）。したがって商社4社は `book_value` の
ままですが、**採用時に WARN を出す**ようにしました
（「上場持分に含み益がある分だけ保守的（過小）」）。

ただし**残高そのものが公正価値で計上されている場合は WARN を出しません**
（6971 の FVTOCI 政策保有株式。方式名は `book_value` でも実質は時価評価）。
`fair_value_based` フラグで区別し、Adjustments Log に記録します。

### §2　負債按分は行わない

脚間の移動はトータルのエクイティ価値を変えないため、按分は行っていません。
構造と限界（負債は時価・資産は簿価という非対称が残ること）を各 overrides の
`_net_debt_derivation` と Adjustments Log に記録しています。

### §4　6971 京セラの一般化 → **解除**

**型F は当たりませんでした**。持分法投資は 97,320 しかなく、KDDI 株は持分法ではなく
**FVTOCI の投資有価証券**です。そこで加算脚を「非連結投資価値（持分法＋政策保有株式）」に
一般化しました。

有報 S100YF47（2026-06-19 提出）注記より 2026年3月31日:

| 項目 | 金額 |
|---|---:|
| FVTOCI 資本性金融資産 合計 | 1,635,466 |
| ├ 市場性のある銘柄 | 1,582,522（**KDDI㈱ 1,530,971** / 京都FG 25,926 / 日本航空 19,550 ほか） |
| └ 市場性のない銘柄 | 52,944 |
| 持分法で会計処理されている投資 | 97,320 |

| − 単体 繰延税金負債 | **420,100** |
| **= 加算脚** | **1,312,686**（1株 1,028円） |

単体 DTL を使うのは、KDDI 株を保有しているのが親会社単体であり、単体の DTL が
ほぼ全額この含み益に対応するためです（単体の事業規模は連結の2割弱）。
連結 DTL 464,045 との差 43,945 は事業側の一時差異とみなし控除していません。

**二重計上チェック（§4 の必須確認）**:
`net_debt` は 借入金（流動 56,075 ＋ 非流動 188,963）＋ リース負債（21,805 ＋ 65,881）
− 現金及び現金同等物 455,887 ＋ 非支配持分 27,941 = **−95,222** で構成され、
**FVTOCI 資本性金融資産も持分法投資も含んでいません**。また受取配当金 46,133 は
IFRS の金融収益（営業利益の下）にあり、コア営業利益 118,138 には含まれていません。
**したがって加算脚との二重計上はありません。** この確認結果は Adjustments Log に記録済みです。

なお京セラは KDDI 株を担保にした借入を行っており、その借入は `net_debt` 側で控除されています
（資産を加算し負債を控除する対称な扱いであって二重計上ではありません）。

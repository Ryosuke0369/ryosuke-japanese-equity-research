# 要手動レビューキュー

バッチモードで自動生成を行わなかった銘柄。キュー送りは失敗ではなく設計上の正常経路（本プロンプト §7-4）。
形式: 銘柄 / 型 / 理由 / 必要な作業。

## 型C/D/E・判定困難（Phase 1 トリアージで確定）

### 8058 三菱商事 — 型C/E相当
- **理由**: NonOp/OP +161.8%。連結OPM 2.81% に対し利益の主柱が持分法投資損益・受取配当金。売上→COGS→SGA→OP の DCF では EV が構造的に過小になる。
- **必要な作業**: (1) 事業投資の持分法損益をセグメント別に分解し SOTP で評価、(2) 資源・非資源の分離、(3) Comps は PER/PBR に切替（EV/EBITDA は基準混在）、(4) 個別プロンプトでの対応（手順書§2 型C 実装例 7203 を参照）。

### 8002 丸紅 — 型C/E相当
- **理由**: NonOp/OP +158.9%。同上。
- **必要な作業**: 三菱商事に同じ。

### 8031 三井物産 — 型C/E相当
- **理由**: NonOp/OP +155.2%。資源持分法（豪州鉄鉱石・LNG）が中核で、営業利益に現れない。
- **必要な作業**: 資源持分法の商品価格感応度を別建てで評価。SOTP 必須。

### 8053 住友商事 — 型C/E相当
- **理由**: NonOp/OP +76.3%、Debt/Revenue 0.64。リース・金融事業を連結。
- **必要な作業**: 金融事業の net_debt を事業ネットキャッシュから分離。SOTP。

### 8001 伊藤忠商事 — 型E
- **理由**: NonOp/OP +70.9% に加え、**オリエントコーポレーション（消費者金融）を連結**。割賦売掛金・金融債務が BS の主要項目で、手順書§2 型E「連結内に金融業を持つ持株会社」に該当。
- **必要な作業**: (1) `de_ratio` の明示指定（自動計算は MI・金融負債を負債扱いし WACC を不当に下げる）、(2) 金融子会社の資産負債を net_debt / NWC から除外、(3) SOTP、(4) Comps は PER/PBR。

### 6301 コマツ — 型C
- **理由**: **Komatsu Financial（販売金融）を連結**。有利子負債の相当部分が金融債権見合い。手順書§2 型C の典型（自動車OEMと同型）。
- **必要な作業**: (1) 短信の「建設機械・車両」と「リテールファイナンス」のセグメント分解、(2) 事業のみDCF、(3) net_debt は事業ネットキャッシュのみ、(4) 金融事業価値を1株あたりで別途加算、(5) Comps は PER/PBR に切替。

### 6326 クボタ — 型C
- **理由**: **Kubota Credit（北米販売金融）を連結**。Debt/Revenue **0.74** は製造業として突出（6301 0.34 / 7011 0.20 / 6902 0.11）。
- **必要な作業**: 6301 に同じ。

### 9434 ソフトバンク — 型E
- **理由**: **PayPay銀行・PayPayカードを連結**（2022年10月に PayPay を連結子会社化）。銀行業の預金・貸出金が net_debt / NWC に混入する。
- **必要な作業**: (1) 金融セグメントを net_debt / NWC から除外、(2) `de_ratio` 明示指定、(3) SOTP（PayPay の評価を別建て）、(4) 上場子会社の有無を最新確認。

### 9101 日本郵船 — 判定困難（持分法主導 + 海運シクリカル）
- **理由**: NonOp/OP +99.7%。利益の主柱が **ONE（Ocean Network Express）の持分法投資損益**で、連結営業利益（OPM 7.73%）には現れない。型B（海運サイクル）と持分法主導が重畳し、Base シナリオを OPM だけで設計できない。
- **必要な作業**: (1) ONE 持分法損益を別建てで評価（コンテナ運賃感応度）、(2) 定期船以外（自動車船・不定期・物流）の連結OPでDCF、(3) 両者を合算する SOTP、(4) 型Bのミッドサイクル正常化を運賃指数ベースで設計。

### 6971 京セラ — 判定困難（保有有価証券主導）
- **理由**: NonOp/OP +77.8%、連結OPM 4.61%（min 1.33%）。**KDDI株式等の投資有価証券が時価総額の相当部分**を占め、事業DCF単独では株価を説明できない。型Cの「金融事業価値+持分法投資は1株あたりで別途加算」と同じ構造。
- **必要な作業**: (1) 保有 KDDI 株の時価を最新確認して1株あたりで別途加算、(2) 税効果（含み益に対する繰延税金負債）の控除、(3) 事業のみのDCF、(4) Comps は事業ベースの倍率に統一。

### 9433 KDDI — 型E（Phase 2 の一次ソース検証で判明・パイロット枠から差し戻し）
- **理由**: EDINET 有報 **docID S100YKG2**（FY2026/3、2026-06-25提出）の連結財政状態計算書に**金融事業専用の科目**が独立して存在することを XBRL 要素名で確認した。
  - `ShortTermLoansForFinancialBusinessCAIFRS` 864,429百万 + `LongTermLoansForFinancialBusinessNCAIFRS` 5,534,048百万 = **金融事業の貸出金 6,398,477百万円（総資産 19,063,364百万円の 33.6%）**
  - `ShortTermDepositsForFinancialBusinessCLIFRS` 5,546,369百万 + `LongTermDepositsForFinancialBusinessNCLIFRS` 120,583百万 = **金融事業の預金 5,666,952百万円（負債合計 13,470,674百万円の 42.1%）**
  - `CallLoanAndBillsBoughtCAIFRS` 33,372百万（コールローン及び買入手形＝銀行固有資産）
  - 関係会社に **auじぶん銀行株式会社**・**au損害保険株式会社** を記載。
- 手順書§2 型E「連結内に銀行を持つ持株会社。銀行業の預金・貸出金は net_debt / NWC に入れない」に**明確に該当**する。パイプラインの自動 net_debt（有利子負債 5,805,637 − 現金 1,078,807 = 4,726,830百万円）は金融事業の調達・銀行預け金を含んでおり、そのままでは EV が汚染される。DSO 194日（通信会社として異常値）も割賦売掛金・与信資産の混入を示す。
- **必要な作業**: (1) 金融セグメント（auフィナンシャルHD）の資産・負債を net_debt / NWC から除外し通信事業のみの net_debt を再構成、(2) **`de_ratio` の明示指定**（自動計算は金融負債を負債扱いし WACC を不当に下げる）、(3) 金融事業価値を1株あたりで別途加算（SOTP 検討）、(4) Comps は EV/EBITDA が基準混在になるため **PER/PBR に切替**、(5) 上場子会社の上場状態を最新確認。
- **備考**: 本銘柄は §1-1 でパイロット枠に指定されていたが、§1-1 の注記（型C/D/E は意図的に除外済み）に反して型E であった。§3-1 の「型C/D/E は生成を試みずキューへ」に従い生成していない。

### 2914 JT（日本たばこ産業） — 型Aだが Comps が成立しない
- **理由**: 型判定は型A（銀行・captive finance なし、NonOp/OP −13.3%）で生成自体は可能だが、**有意な比較対象が海外たばこ（Philip Morris / BAT / Altria / Imperial Brands）しか存在しない**。§5 は「海外Peer は為替・一次ソース検証が必要なためバッチではキュー送り」と定めており、国内 食料品 Peer（アサヒ OPM 6.4% / キリン 8.6% / 味の素 12.1%）は **OPM 24.6% のたばこ事業と economics が根本的に異なる**ため、Peer中央値から導出する `exit_multiple` の根拠が確保できない。時価総額 12.08兆円 に対し §5 のバンド（3.62〜36.2兆円）に入る国内食品企業も存在しない。
- **参考データ（取得済み）**: 時価総額 12,077,800百万円 / 株価 6,803円（2026-09-04）/ 株数 1,775,357,592 / net_debt 847,553（有利子負債 1,678,688 − 現金 831,135）/ FY2025/12 売上 3,467,675・営業利益 853,707（OPM 24.62%）/ 実績OPM min 9.86（FY2024・一過性費用）・med 23.83・max 24.62% / D&A 195,899 / capex 162,386 / DSO 67・DIH 247・DPO 176日。
- **一次データ由来の警告**: yfinance の `Interest Expense` は **195,194百万円** で、平均有利子負債 1,702,738百万円 に対し **11.5%** となり実勢とかけ離れている（たばこ税等の別項目を含んでいる疑い）。**実績Kd の算出にこの値を使ってはならない**。
- **必要な作業**: (1) 海外たばこ4社の財務を一次ソースで取得し為替換算して comps CSV を作る（`docs/overrides_schema.md` の `285A_comps.csv` / `7203_comps.csv` の運用に倣い、FXレートと as-of を表に記録する）、(2) EDINET 有報から支払利息の実額を取得して実績Kdを算出、(3) FY2024 の OPM 9.86% への落ち込みの原因（一過性費用の内訳）を確認し Downside 2 の設計に反映。

### 4519 中外製薬 — 型Aだが減価償却費が機械取得できない（追補2 §G ゲート不通過）
- **理由**: 型判定は型A（プレスクリーン CLEAN、docID S100XTBJ）で生成自体は可能だが、**減価償却費（期間費用）がどちらのソースからも取得できない**。
  - **yfinance**: キャッシュフロー計算書に `Depreciation And Amortization` 行が存在しない（`cashflow` は `Operating Cash Flow` と `Capital Expenditure` の2行のみ）。損益計算書の `EBITDA` は `EBIT` と同値で D&A が織り込まれていない。
  - **EDINET有報XBRL**: 連結CF計算書が Roche 流の集約表示（`CashGeneratedFromOperationsOpeCFIFRS` → `SubtotalOpeCFIFRS`）で、**D&A が独立要素としてタグ付けされていない**。`Depreciation` / `Amortization` を含む要素は減価償却累計額（instant コンテキストの残高）のみで、期間費用ではない。
- **結果**: `core_ebitda` が算出できず、追補2 §G が定めた品質ゲート（`batch/check_core_ebitda.py` の一致確認）を通せない。Comps の `Via EV/EBITDA (Median)` は N/A になる（4151 で発生した事象と同型）。**D&A を推定で埋めることは v2 §10「数値の推測埋め」に該当するため行わない**。
- **同じ理由で、本バッチの他の医薬品銘柄（4151 / 4502 / 4503 / 4507 / 4523 / 4568 / 4578）の comps CSV からも 4519 を除外している**（v2 §5「D&Aが取れない社はCSVに入れない」）。時価総額 11.18兆円 の大型株が製薬 Peer 群から抜けている点は各サマリーに開示済み。
- **参考データ（取得済み）**: 時価総額 11,181,700百万円 / 株価 6,795円（2026-09-04）/ 株数 1,645,577,167 / 現金 426,602・有利子負債なし → net_debt −426,602（ネットキャッシュ）/ FY2025/12 売上 1,257,941・営業利益 598,833（**OPM 47.60%**、観測窓の最高）/ 実績OPM min 39.52・med 44.32・max 47.60% / capex 111,607（売上比 8.9%）/ DSO 129・DIH 278・DPO 128日 / beta 0.546（クランプ域内、そのまま使用可）。
- **必要な作業**: (1) 有価証券報告書の**注記（セグメント情報または固定資産の増減表）から減価償却費・償却費の実額を人手で読み取る**、(2) それを `core_ebitda` および `hist_depreciation` として overrides に投入、(3) 生成後に `batch/check_core_ebitda.py` で一致を確認、(4) あわせて他の医薬品7銘柄の comps CSV に 4519 を Peer として追加し、Exit 倍率を再導出して再生成するかどうかを判断する。

### 7741 HOYA — 型Aだが yfinance の損益計算書が構造的に誤マッピングされている
- **理由**: 型判定は型A（プレスクリーン **CLEAN**、docID S100TOTA）だが、**yfinance の損益計算書が使えない**。yfinance の FY2026/3 は 売上 995,844 / 営業利益 551,126（**OPM 55.3%**）/ COGS 135,904（13.6%）/ SGA 17,973（1.8%）としているが、**HOYA の実際の OPM は30%前後**であり、この水準は成立しない。
- **一次ソースによる誤マッピングの特定（追補1 §D-3 の数値照合）**: EDINET 有報 **docID S100TOTA**（FY2024/3、取得日 2026-09-05）の XBRL と突合した結果、原因が特定できた。
  - `RevenueIFRS` = **762,610** / `Revenue2IFRS`（収益合計）= **792,628** ← yfinance の売上 792,628 はこちらに一致
  - `TotalExpensesIFRS` = **556,064** → 792,628 − 556,064 = **236,564** = `ProfitLossBeforeTaxIFRS` に一致（**実勢OPM ≈ 29.8%**）
  - `RawMaterialsAndConsumablesUsedIFRS` = **103,855** ← yfinance の COGS 104,638（FY2024/3）はこれにほぼ一致
  - `ProfitLossAttributableToOwnersOfParentIFRS` = **181,377** ← yfinance の純利益と**完全一致**
  - → **yfinance は「原材料及び消耗品費」を売上原価として取り込んでおり、そのため売上総利益と営業利益が大幅に過大**になっている。純利益と売上だけが正しい。
- **なぜ自動修正できないか**: EDINET から取得できる最新の有報は **FY2024/3（S100TOTA）** で、`get_document_ids` は num_years=5 でも FY2025/3・FY2026/3 の提出書類を返さない（同じ検索でパナソニックの FY2026/3 S100YETA は取得できているため、フェッチャ側の探索の問題と思われる）。**誤マッピングの事実は一次ソースで確認できたが、FY2025/3・FY2026/3 の正しい営業利益・売上原価は取得できない**。推定で埋めることは v2 §10「数値の推測埋め」に該当するため行わない。
- **追加の問題（追補3 §M）**: **yfinance の beta が `None`**。テンプレートは黙って 1.0 にフォールバックするため、生成すると `1.0*` フォールバック銘柄になる。β再導出リストに登録する。
- **参考データ（取得済み・信頼できるものだけ）**: 株価 24,140円（2026-09-04）/ 株数 334,520,495 / 時価総額 8,075,325百万円 / 現金 574,092・有利子負債 42,241 → **net_debt −531,851（ネットキャッシュ）** / CF系（OCF 278,446 / capex 56,581 / D&A 58,218）は CF計算書由来で誤マッピングの影響を受けにくい / DSO 77・DIH 356・DPO 185日。**売上・営業利益・COGS・SGA は使用不可**。
- **必要な作業**: (1) FY2025/3・FY2026/3 の**有価証券報告書または決算短信から 売上収益・営業利益・売上原価・販管費の実額を一次ソースで取得**し overrides に明示指定、(2) 取得した docID と取得日を Adjustments Log に記録（追補3 §O）、(3) **β を一次ソース（TOPIX 対比の実測 or 業界β）から再導出**して明示指定、(4) 生成後に `batch/check_core_ebitda.py` と `batch/check_market_data.py` を通す。

### 9202 ANAホールディングス — 型Aだが Peer セットが成立しない（国内の比較対象が JAL 1社のみ）
- **理由**: 型判定は型A（後述のプレスクリーン所見も非該当）で生成自体は可能だが、**exit_multiple の根拠となる Peer セットが作れない**。
  - 日本の上場航空会社は **ANA と JAL の2社のみ**。対象を除くと Peer は **9201 JAL 1社（EV/EBITDA 3.10x）** しかなく、
    中央値も四分位バンド（追補7 §AA が要求する p25/p75）も構成できない（`batch/arbitrate_divergence.py` は n≥3 を要求する）。
  - 陸運（鉄道）で埋めると **Peer中央値が 10.17x** になるが、これは**鉄道の倍率**である。
    実測値: 9020 JR東日本 10.17x / 9021 JR西日本 7.27x / 9042 阪急阪神 12.41x / 9005 東急 11.57x に対し、
    **JAL 3.10x / ANA自社 4.93x**。**市場は航空と鉄道をまったく別の倍率で評価している**（3〜4倍の開き）。
  - 鉄道と航空は資産の耐用年数（鉄道インフラ 50年超 vs 航空機 20年前後）・需要の循環性・規制構造が大きく異なり、
    EV/EBITDA を横断的に当てる根拠がない。**10.2x を採ると Target が実勢の2倍規模に膨らむ**。
- **v2 §5 の適用**: 「事業比較可能性を第一基準とする」に従えば有効な Peer は JAL 1社のみ。
  海外航空会社（Delta / United / Lufthansa / Singapore Airlines 等）を使う選択肢はあるが、

## 4. 8001 が型E パスで解け、総合商社4社が解けない理由の差分

**両者は「連結内に金融がある」点では同じに見えるが、ブロッカーの所在が違う。**

| | **8001 伊藤忠（解ける）** | **8002 / 8031 / 8053 / 8058（解けない）** |
|---|---|---|
| 利益の主柱がどこにあるか | **連結営業利益の中**にある。オリコは連結子会社で、その損益は連結PLに取り込まれている | **連結営業利益の外**にある。持分法投資損益・受取配当金が主柱で、NonOp/OP が **+155.2%（8031）/ +161.8%（8058）** |
| BS 上の見え方 | 割賦売掛金・金融債務が**独立科目**として立っており、金融部門を機械的に切り出せる | 「持分法で会計処理されている投資」という**1行**。事業別の内訳は BS には無い |
| 型E パス（銀行/金融の分離＋SOTP）を当てるとどうなるか | 金融部門を `net_debt` / NWC から除外し、非金融部門を DCF、金融部門を PBR で評価すれば**完結する** | 金融を切り出しても、**残った本体の営業利益が利益の実態を表さない**。連結OPM 2.81%（8058）で DCF を組めば EV は構造的に過小になる |
| 追加で必要になるもの | セグメント注記（既存の開示で足りる） | **セグメント別持分法損益**の一次取得と、**各投資先をどう評価するかの設計判断**（資源持分法なら商品価格感応度など） |

**要するに、8001 は「連結の中から金融を引き算する」問題で、商社4社は「連結PLに現れない利益をどう足すか」という問題である。**

## 6. 追記（2026-09-07、タスク3 型D/E 実施後）

### 6-1. 4689 の型判定を **D → E に訂正**

§3 の台帳で 4689 LINEヤフーを型D としたのは誤りである。本タスクで
`batch/fin_business_screen.py` に型ルーティングを実装し、EDINET XBRL の
金融科目を**資産側と負債側に分けて**総資産比を測ったところ、次のようになった。

| 銘柄 | 金融**資産**／総資産 | 金融**負債**／総資産 | 判定 |
|---|---:|---:|---|
| 4689 LINEヤフー | **39.9%**（銀行貸出金14.4 + 銀行有価証券13.8 + カード貸付金11.2 + コールローン0.5） | 24.1%（銀行預金） | **型E** |
| 9433 KDDI | **37.5%**（貸出金33.5 + 有価証券3.7 + コールローン0.2） | 29.7%（預金） | **型E** |

構造がほぼ同じであり、9433 を型E とするなら 4689 も型E である。台帳が 4689 を
型D としたのは「銀行預金 24.11% + 銀行貸出金 14.42% + 銀行有価証券 13.84% +
カード貸付金 11.18%」を**合算して 63.5%** と読んだためだが、この合算は預金（負債）と
貸出金（資産）という**同じ事業の裏表を二度数えている**。資産側だけで測れば 39.9% で、
連結資産の過半には届かない＝非金融が主体であり、DDM/RI ではなく SOTP で解く。

なお、実装当初の classify() も同じ誤りを別の形でしていた（`ForFinancialBusiness` が
`ShortTermDepositsForFinancialBusinessCLIFRS` にも当たり、9433 の預金を資産として
数えて 67.2% → 型D と出していた）。IFRS タグが名前に持つ側面標識
（`...AssetsIFRS` / `...CAIFRS` / `...NCAIFRS` = 資産、`...LiabilitiesIFRS` /
`...CLIFRS` / `...NCLIFRS` = 負債）で分ける実装に直してある。

**結果として、本セッションで生成した型D モデルは 8410 セブン銀行のみである。**
型D パス（DDM + Residual Income）は 8410 で検証済みだが、キューの中に
追加の型D 銘柄は無かった。

### 6-3. 残り3件に足りないもの（具体的に何を取れば解けるか）

型E の DCF+SOTP を組むのに必要な入力は、9433 で確定した通り次の6点である。

1. 非金融ベースの売上高・営業利益（連結消去後）
2. 非金融ベースの有利子負債・現預金
3. 非支配株主持分（金融子会社に帰属する分の有無）
4. 金融子会社の**純資産**と**議決権比率**
5. 金融子会社の売上高・営業利益（SOTP のセグメント表示用）
6. 金融ピアの PBR（本タスクでは 5838 / 8410 / 7182 / 8570 の中央値 1.359 を使用）

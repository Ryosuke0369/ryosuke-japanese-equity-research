### 3-2. 型E（銀行を連結に持つ事業会社）: 非金融DCF + 金融PBR の SOTP

既存の SOTP エンジン（`templates/sotp_template.py`）は全セグメントを EV/EBITDA で
評価するため、型E を表現できなかった。セグメントに `valuation_method: "pbr"` を追加し、
**基数を純資産、倍率を PBR、結果を EV ではなく株主価値**にする経路を新設した。

Equity Bridge も型E 用に分岐する:

```
非金融 EV − 非金融 net debt = 非金融の株主価値
  + 金融セグメント株主価値（PBR × 純資産）
  = SOTP 株主価値 → ×(1−ディスカウント) → − 非支配株主持分
```

金融子会社の株主価値は**自身の預金を既にネットしている**ため、EV に足してから親の
net debt を引くと資金調達を二重に控除する。だから net debt 控除の**後**に加算する。
Sensitivity の表1・表2 も同じブリッジで組み直した（片方だけ旧式だと感応度表が
SOTP Valuation シートと食い違う）。

**overrides 契約**（`company_type: "E"` 宣言時、実行前にエラー停止）:
`net_debt` / `de_ratio` / 非金融 P/L（`segments` または `hist_*`）/ `sotp` の4点を明示必須。
特に **de_ratio の自動計算は禁止**（自動計算は `net_debt ÷ 時価総額` なので、
金融込みの連結 net_debt を使うと WACC の資本構成が金融の資金調達で膨らむ）。
terminal capex/D&A の警告は従来どおり存置。

**9433 KDDI（型E、89件目）**

KDDI は「auフィナンシャルホールディングスを除く連結ベース」の P/L・BS を**会社自身が
開示している**（2026年3月期 決算詳細資料 2026-05-12 p.3）。連結消去後の非金融系列が
推計なしで得られる。

| 入力 | 値 | 出所 |

| 非金融 有利子負債 | 3,269,350 | 同上 ＋ 有報 S100YKG2 の記述と一致 |
| 非金融 net debt（現預金控除後） | 3,060,157 | 同上 |
| 非支配株主持分 | 515,952 | 有報 S100YKG2 連結BS |

| 結果 | 値 |
|---|---:|

**DCF と SOTP が大きく食い違っている**（4,220 対 2,657）。原因は明確で、
WACC 5.61% に対し g 1.00% なので永久成長の分母が 4.61% しかなく、PGM の終価が
効きすぎることによる。SOTP 側は 8.1x EV/EBITDA という観測倍率で組んでいるため
はるかに保守的である。手順書 §2 では**型E の主手法は SOTP** であり、SOTP 2,657 を
主、DCF 4,220 を参考と読むのが正しい。この乖離自体は §X 裁定の対象外である
（裁定は DCF 2脚の間の乖離を見るもので、1.56x と閾値内）。

## 7. 指示との差異

**(a) 台帳の 4689 を型D → 型E に訂正した。**
タスク1 の台帳で 4689 を型D としたのは、「銀行預金 24.11% + 銀行貸出金 14.42% +
銀行有価証券 13.84% + カード貸付金 11.18% = 63.5%」と読んだためだが、この合算は
預金（負債）と貸出金（資産）という**同じ事業の裏表を二度数えている**。資産側だけで
測れば 39.9% であり、9433 の 37.5% とほぼ同じ構造である。9433 を型E とするなら
4689 も型E であり、片方だけ DDM/RI に送る理由がない。結果として、**本セッションで
生成した型D モデルは 8410 のみ**である（キューに追加の型D 銘柄は無かった）。

**(b) §6 の4件のうち3件を生成していない。** 理由は §6 のとおり。

（既報の差異: §2-4 で yfinance の beta フィールドではなく TOPIX 回帰を採用した件、
追補12 で Adjustments Log への記録を追加した件、追補13 §A で既存の §Z 鮮度チェックを
緩めず新しい開示ヴィンテージ経路 check 23 を作った件は、フェーズ2 v2 報告に記載済み。）
